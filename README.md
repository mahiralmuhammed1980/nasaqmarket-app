# نسق ماركت

تطبيق أندرويد (هاتف وتابلت، واجهة عربية RTL) للمحاسبة وإدارة المخزون للمحلات التجارية: بقالية/سوبر ماركت، ملابس، أحذية، كهربائيات وغيرها.
**كل البيانات على الهاتف** (SQLite) مع نسخ احتياطي ومزامنة إلى Google Drive الخاص بالمستخدم. لا خادم لدينا.

## المبدأ
- **تسجيل الدخول بحساب Google إلزامي** لضمان وجود Drive. يُطلب نطاق `drive.appdata` فقط (مجلد مخفي خاص بالتطبيق، نطاق غير حساس).
- **الإعداد الأول** يختار المستخدم نوع النشاط فتُضبط الميزات (ويمكن تغييرها من الإعدادات):

| النوع | مقاس/لون | كميات عشرية (وزن) | تاريخ صلاحية |
|---|---|---|---|
| سوبر ماركت / بقالية | – | ✓ | ✓ |
| ملابس / أحذية | ✓ | – | – |
| كهربائيات / عام | – | – | – |

- **المقاس واللون:** كل توليفة صنف مستقل (باركود ومخزون وسعر)، ومولّد توليفات عند إنشاء الصنف.
- **تاريخ الصلاحية اختياري لكل صنف:** عند تفعيله تظهر حقول الدفعة والانتهاء ويُخصم الأقرب انتهاءً أولاً (FEFO) وتظهر تنبيهات الانتهاء.
- **الكميات** تُخزَّن عشرية مقرّبة إلى 3 منازل (`q3`) لتفادي أخطاء الفاصلة العائمة؛ والمبالغ أعداد صحيحة.
- **الزبون اختياري في الفاتورة** (الافتراضي «زبون نقدي»).

## الميزات
لوحة التحكم (مبيعات، ربح الشهر، ديون الزبائن والموردين، منخفض المخزون، المنتهي) • المخزون والتصنيفات • مسح الباركود بالكاميرا (EAN وGS1) • الفواتير (PDF عربي، مشاركة، طباعة، دفع جزئي، إلغاء مع إرجاع الكميات) • الموردون وأوامر الشراء والاستلام وكشف حساب المورد • الصندوق (دخل/خرج بنقد/بطاقة/حوالة، مصاريف، إغلاق يومي) • استيراد الجرد من Excel/CSV وتصدير • نسخ احتياطي تلقائي يومي إلى Drive واستعادة عند تبديل الهاتف • قفل PIN • شعار المحل.

## التطوير
```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # عند تعديل lib/data/tables.dart
flutter analyze && flutter test
flutter run --dart-define=DEV_BYPASS_LOGIN=true             # تجاوز تسجيل Google في وضع debug فقط
```
البنية: `lib/data` (جداول drift والمستودع والاستيراد) • `lib/core` (التنسيق، أنواع النشاط) • `lib/services` (حساب Google، Drive، PIN، PDF) • `lib/ui` (الشاشات) • `firebase/public` (صفحة التطبيق وسياسة الخصوصية للاستضافة فقط).

> الإصدار الأول لقاعدة البيانات هو `kSchemaVersion = 1` (بلا ترحيل). عند أي تعديل لاحق في الجداول: ارفع الرقم وأضف خطوة ترحيل في `lib/data/database.dart` مع اختبار ترحيل (`drift_dev schema`).

## الإعداد لمرة واحدة (منك)
1. **Google Cloud:** أنشئ مشروعاً، فعّل *Google Drive API*، واضبط *OAuth consent screen* (Branding: صفحة التطبيق وسياسة الخصوصية من `firebase/public`، استبدل `CONTACT_EMAIL` في `privacy.html`).
2. **عملاء OAuth:** أنشئ *OAuth client* من نوع **Android** (الحزمة `com.nasaq.market` + بصمة SHA-1 لمفتاح الرفع **ومفتاح Play App Signing** بعد إنشائه في Play Console) وآخر من نوع **Web** (ينسخ معرّفه إلى سر `GOOGLE_SERVER_CLIENT_ID`).
3. **مفتاح الرفع:**
   ```bash
   keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias nasaq
   ```
   احتفظ بنسخة من الملف وكلمة المرور في أكثر من مكان.
4. **أسرار GitHub (Actions):** `ANDROID_KEYSTORE_BASE64` (`base64 -w0 release.jks`)، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`، `GOOGLE_SERVER_CLIENT_ID`.
5. **صفحة الخصوصية:** `cd firebase && firebase deploy --only hosting --project <المشروع>`.

## النشر على Google Play
شغّل *Actions → Release AAB* ونزّل `app-release.aab` ثم ارفعه في Play Console (اختبار داخلي ← مغلق ← إنتاج). ارفع `version` في `pubspec.yaml` عند كل إصدار (الرقم بعد `+` يزيد دائماً). التحديث للمستخدمين عبر Play. لا يوجد تحديث ذاتي ولا صلاحية تثبيت APK.

## الفترة المجانية ثم الاشتراك
التطبيق **مجاني التحميل دائماً** (تطبيق Play المجاني لا يتحول لمدفوع التحميل). الدفع لاحقاً اشتراك داخل التطبيق عبر Google Play Billing (`in_app_purchase`).
- `kFreeUntil` في `lib/services/access.dart` هو آخر يوم مجاني (مؤقتاً 2027-03-01؛ **غيّره عند النشر**). يظهر في التطبيق شريط «مجاني حتى ...».
- بعد التاريخ: قراءة وتصدير فقط (المستودع يرفض الإضافة والتعديل بـ `ReadOnlyMode`)، ولا يُحذف أي شيء. الشرط موجود في الإصدار الأول نفسه فلا تبقى نسخة قديمة مجانية للأبد.
- تمديد/تقصير الفترة بلا إصدار جديد: انشر ملف JSON عاماً `{"freeUntil":"2027-03-01"}` ومرّر `--dart-define=FREE_UNTIL_URL=<الرابط>` عند البناء.
- حارس الساعة: إرجاع ساعة الهاتف للوراء لا يعيد الفترة المجانية.
- الخطوة التالية: ربط الاشتراك (يضبط `AccessPolicy.subscribed`).

## حدود معروفة
- قاعدة البيانات غير مشفّرة على القرص (محمية بعزل تطبيقات أندرويد).
- لا تزامن حي بين الأجهزة: نسخ واستعادة عبر Drive.
